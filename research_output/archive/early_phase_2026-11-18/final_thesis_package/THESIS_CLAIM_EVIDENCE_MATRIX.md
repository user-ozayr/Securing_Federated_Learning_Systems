# Thesis claim-to-evidence matrix

This matrix separates source-code presence from validation. ?Tested? refers only to the named evidence; it does not imply cross-host deployment or adversarial certification.

| Claim | Implementation location | Experimental evidence | Status | Limitation |
|---|---|---|---|---|
| Flower federated-learning architecture coordinates client training and aggregation | `src/fl_security/federated/flower_simulation.py`, `src/fl_security/federated/training.py`, `src/fl_security/federated/model.py` | Same-host one-round tiny Flower/SPDZ2k log: `RAW_EXPERIMENT_RESULTS/flower_chunked_tiny_integration.log` (3 clients, 3 parties, 8 parameters, 16.32 s); full suite | IMPLEMENTED AND TESTED | Synthetic tiny model only; no full CNN training/accuracy result.

| Weighted FedAvg arithmetic matches an independent reference | `mp_spdz.py:_encode_weighted_model`, `receive_weighted_average`; `spdz2k_weighted_sum.mpc` | Direct probes use counts [1,2,3], deterministic inputs, Python reference; max absolute decoded error 0 at each completed size; 77-test suite | IMPLEMENTED AND TESTED | Test values are synthetic, not trained CNN client updates; fixed-point/ring bounds remain assumptions for general model states.
