Historical raw run evidence is copied in `raw_evidence/`. Successful execution sizes: 8, 1,000, 10,000 (corrected retry), 50,000, and 100,000. The first 10,000 run failed with `unexpected data length`; the 250,000 run hit its 300-second cap and is ABORTED. These are same-host loopback vector benchmarks, not cross-host or full-model experiments. Loopback byte counts are host interface counters and are not per-party wire accounting. CPU seconds are summed estimates across three parties. Fixed-point scale, compile duration for these runtime attempts, and max numerical error versus a plaintext reference were not captured; blank/`not recorded` values are intentionally not invented. The separate `raw_evidence/scalability_phase/SCALING_BENCHMARKS.csv` records compilation only through 2,122,187 input elements; do not interpret it as MPC execution. The fresh tiny Flower integration is separately logged and is not represented as a large-vector benchmark.
